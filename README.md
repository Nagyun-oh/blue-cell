# BLUE 고객지원 보안 실습

CoC (Blue).pdf를 참고한 Python 3.11+ 웹서비스입니다. 외부 Python 패키지 없이 실행합니다.

## 실행

PowerShell에서 이 폴더로 이동한 다음 실행합니다. 첫 실행 비밀번호를 직접 지정하세요.

```powershell
$env:ADMIN_PASSWORD = '관리자용-12자-이상-비밀번호'
$env:USER_PASSWORD = '일반유저용-12자-이상-비밀번호'
$env:LAB_XSS = '1'
$env:LLM_API_URL = 'https://YOUR-PROVIDER/v1/chat/completions'
$env:LLM_API_KEY = 'YOUR-KEY'
python server.py
```

브라우저에서 http://127.0.0.1:8000 에 접속합니다. 초기 계정은 `admin` / `admin@example.test`, `user` / `user@example.test`입니다. 가입 전에 `ADMIN_EMAIL`, `USER_EMAIL` 환경변수로 바꿀 수 있습니다. 비밀번호는 위에서 직접 지정한 값입니다. 초기 계정은 DB가 비어 있을 때 한 번 생성됩니다. 추가 가입자는 일반 권한만 얻습니다.

## LLM 연결

`LLM_API_URL`은 OpenAI 호환 **전체 chat completions 엔드포인트**입니다. 모델은 `llama-3.2-3b-instruct`로 고정되어 있습니다. 그 모델 이름을 제공하는 공급자 또는 로컬 호환 서버가 필요합니다. API를 설정하지 않으면 상담 시작 인사는 표시하지만 분류 시 명확한 연결 오류를 표시합니다. 가짜 모델 응답이나 임의의 대체 모델을 사용하지 않습니다.

서버가 대화 순서와 계정 일치를 검사합니다. 일치하지 않으면 토큰을 만들지 않고 LLM에도 토큰을 보내지 않습니다. 일치한 계정의 아이디·이메일·토큰을 포함한 프롬프트로 호출하며, 응답이 허용된 문자열과 정확히 같을 때만 해당 응답을 사용자에게 전달합니다. 모델 오류 시 토큰은 발급되지 않습니다. 정상 토큰은 10분 후 만료되며 1회 사용 후 폐기됩니다. 비밀번호 변경 시 기존 세션도 모두 만료됩니다.

## 실습 옵션과 접근 경계

- `LAB_XSS=1`: 문의 상세 본문에서만 HTML을 그대로 출력하며, 세션 쿠키의 HttpOnly를 끕니다. 의도된 Stored-XSS 실습 조건입니다. 제목과 나머지 화면의 사용자 입력은 HTML로 해석하지 않습니다. 실습 시작 명령에 이 옵션을 포함했습니다.
- 옵션을 생략하거나 `0`으로 설정하면 문의 본문을 이스케이프하고 세션 쿠키를 HttpOnly로 보호합니다. 이 상태는 PDF의 의도된 XSS 조건을 충족하지 않습니다.
- 관리자는 전체 문의, 일반 사용자는 본인 문의만 조회합니다. Red 문의는 관리자가 목록에서 직접 선택해 열람합니다. 외부 메시지나 문서 속 요청을 자동으로 실행하지 않습니다.
- 로그인 세션은 1시간이며 최초 접속 IP와 일치할 때만 유효합니다. DB에는 세션과 재설정 토큰의 SHA-256 해시를 저장합니다.
- 비밀번호는 salt와 PBKDF2-HMAC-SHA256 300,000회로 저장합니다. SQL은 매개변수화합니다. POST는 JSON 및 정확한 Origin을 요구합니다. IP·경로별 분당 30회 제한을 적용합니다.

## 외부 배포 설정

이 결과물은 **로컬 실행용이며 외부 배포는 완료되지 않았습니다.** Sites 생성 도구가 Windows 사용자 경로 realpath EPERM 오류로 실행되지 않아 Python 서버로 구성했습니다. Sites의 Workers 런타임에 이 Python 서버를 그대로 올릴 수는 없습니다.

별도 Python 호스트에서 HTTPS 역방향 프록시 뒤에 실행할 수 있습니다. 영구 저장소에 `DATABASE_PATH`를 지정하고, 비밀 값은 호스트 환경변수로 설정하세요. `PUBLIC_ORIGIN`은 실제 HTTPS 주소, `BIND`는 필요한 바인딩 주소, `PORT`는 서버 포트로 지정합니다. 기본값은 로컬 전용 127.0.0.1:8000입니다.

IP 바인딩을 정확하게 적용하려면 `TRUSTED_PROXY_IPS`에 실제 직전 프록시 IP만 쉼표로 지정합니다. 이 프록시는 클라이언트의 `X-Real-IP`를 제거하고 실제 접속 공인 IP로 덮어써야 합니다. 백엔드 포트는 프록시에서만 접근하도록 제한합니다. 임의의 X-Forwarded-For를 신뢰하지 않습니다. 신뢰 프록시가 없는 직접 접속에서는 TCP 상대 IP를 사용합니다. 서로 다른 외부 공인 IP에서 배포 후 검증해야 합니다.

표준 라이브러리 HTTP 서버이므로 인터넷 서비스 운영용으로 검증된 배포 스택은 아닙니다. 제한된 보안 실습 환경용 구현입니다. 실제 데이터나 기존 운영 서비스의 인증정보를 사용하지 마세요.

## 검증

```powershell
python test_server.py
```

테스트는 임시 DB와 로컬 모의 LLM을 사용합니다. 가입·로그인, 문의 권한, IP가 다른 세션 거절, 요청 출처 검사, 불일치 정보에 대한 LLM 미호출, 정확한 모델명 및 프롬프트 필드, 토큰 1회 사용, 비밀번호 변경 후 세션 무효화, 비복구 상담 종료를 확인합니다.

실제 공급자 LLM 응답, 브라우저에서의 Stored-XSS 실행 및 세션 재활용, 실제 공인 IP 경계, 외부 HTTPS 배포는 별도 검증이 필요합니다. 모의 LLM 통과를 실제 LLM 연결 성공으로 간주하지 않습니다.
